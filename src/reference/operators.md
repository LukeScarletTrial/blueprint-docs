# Operators & Expressions

Blueprint provides a comprehensive set of arithmetic, logical, and comparison operators.

## Arithmetic Operators

| Operator | Operation | Example |
| :---: | :--- | :--- |
| `+` | Addition (or string concatenation) | `a + b`, `"Hello " + name` |
| `-` | Subtraction or Unary Negation | `a - b`, `-10` |
| `*` | Multiplication | `w * h` |
| `/` | Integer Division | `total / count` |

## Comparison Operators

Comparison operators evaluate to a `bool` (`true` or `false`):

| Operator | Description |
| :---: | :--- |
| `==` | Equality |
| `!=` | Inequality |
| `<` | Less than |
| `<=` | Less than or equal to |
| `>` | Greater than |
| `>=` | Greater than or equal to |

## Logical Operators

| Operator | Description | Example |
| :---: | :--- | :--- |
| `&&` | Logical AND | `is_valid && score > 50` |
| `\|\|` | Logical OR | `is_admin \|\| has_permission` |
| `!` | Logical NOT | `!is_closed` |
