# Hello World Tutorial

Let's look at the default program generated by `printable init`:

```blueprint
@blueprint import Blueprint
Blueprint.Setup("Blueprint App", true)

func Main(): [
    output("Hello, World!")
]
```

## Anatomy of the Program

1. **`@blueprint import Blueprint`**: An annotation declaring that this file utilizes the core Blueprint framework.
2. **`Blueprint.Setup(name, use_deps)`**: Registers app configuration metadata at initialization.
3. **`func Main(): [...]`**: Defines the application entry point. Every executable Blueprint program requires a `Main()` function.
4. **`output("Hello, World!")`**: Standard library call that prints to `stdout` with an automatic trailing newline.

## Running the Code

To run the program via the fast developer interpreter:

```bash
printable run
```

Output:
```text
Hello, World!
```

## Compiling to Native Machine Code

To compile `main.bl` directly into an optimized standalone native executable:

```bash
printable build
```

This generates `bin/main.exe` (or `bin/main` on Linux/macOS). You can execute it directly without any runtime or interpreter:

```bash
.\bin\main.exe
```
